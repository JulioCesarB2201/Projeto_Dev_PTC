# Projeto Dev PTC
Este projeto foi desenvolvido durante o processo seletivo do CITI.

O site apresenta informações sobre a empresa PTC e foi pensado para oferecer, futuramente, uma funcionalidade de solicitação de orçamentos de produtos.
Atualmente, a área de orçamentos ainda não está implementada — ela foi planejada para demonstrar o potencial de expansão do site.

## Tecnologias Utilizadas
- HTML

- CSS
